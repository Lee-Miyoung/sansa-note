# 산사노트 2.5D 원화 · 2026-11-02

산사노트용으로 새로 생성한 수채화입니다. 특정 사찰·문화재를 복원하거나 촬영한 그림이 아닙니다. 기존 평면 법당을 확대·분할하지 않았습니다.

- `originals/*.png`: 생성된 고해상도 원본 13개. 건축 1536×1024, 불단 1024×1536, 전경 1536×1024.
- `{id}-altar.webp`, `{id}-altar-small.webp`: 각 본존·광배·연화대·불단 전체를 포함하는 독립 투명 레이어. 원본 전체와 알파를 보존한 1024/640px 버전.
- `architecture.webp`: 대웅전 건축. 나머지 다섯 전각은 `{id}-architecture.webp`. 모바일용 `-small.webp`는 768px.
- `foreground.webp`, `foreground-small.webp`: 공용 마루·방석·향로·공양물 전경. 상단은 투명합니다.

생성 지시에는 각 존상의 대표 도상, 손·지물·광배의 완전한 프레임, 한국 목조 법당의 원근감, 중앙이 빈 건축, 텍스트·사람·과장된 빛 효과 배제를 명시했습니다. 석가모니불은 촉지인, 아미타불은 선정인, 관음은 화불 보관·연꽃, 문수는 보관·경책을 얹은 연꽃·사자 장식, 약사는 약그릇, 지장은 삭발·석장·보주로 구별했습니다.

원본 PNG를 육안으로 보고 얼굴·손·지물·투명 경계와 여섯 최종 합성 화면을 확인했습니다. 불교미술 전문가의 감수를 받은 결과는 아닙니다. 문화 참고자료와 미검증 사항은 [개선 보고](../../../docs/online-sansa/automatic-25d/README.md)에 구분했습니다. 해시·파일 크기는 [자산 목록](../../../docs/online-sansa/automatic-25d/assets.json)에 있습니다.
