# 산사노트 추가 일러스트 제작 사양

이번 구현은 사용자가 올린 캐릭터·로고·산·연꽃·목탁·염주·붓·지도 PNG를 우선 사용했다. `images/brand/wellness/props/*.webp` 16개는 기존 파일의 경량 파생본이다. 새로운 장소나 문화유산을 창작하지 않았다. 원본은 모두 보존했다. 캐릭터 시트도 WebP 파생본으로 제공하여 1,743,332바이트에서 366,764바이트로 줄였다.

현재 대화에서 확인 가능한 레퍼런스는 메인 화면 시안 한 장이다. 내부 화면은 첨부 지시서의 11개 콘셉트를 따랐다. 두 번째 내부 시안의 세부 도안과 일치한다고 주장하지 않는다.

아래 파일은 **향후 제작용 사양이며 아직 생성·등록하지 않은 파일**이다. 기존 소품 조합으로 동작하는 UI는 이미 구현했다. 캐릭터 원본은 `images/brand/wellness/companion-poses.png`, 얼굴·머리 비율·베이지 상의·올리브색 바지·수채화 선을 고정한다. 눈·입·손의 형태가 달라지는 그림은 채택하지 않는다. 종교 문양을 추가하기보다 일상 행동과 표정에 집중한다.

| 제작 파일명 | 용도·구성 | 제작 사양 |
|---|---|---|
| `scene-tea-garden.webp` | 처방: 꽃 정원, 나무 탁자, 찻주전자와 두 잔. 입력·편지 영역 비워 두기 | 1200×800, 배경, 글씨 없음, 180KB 목표 |
| `monk-listening-tea.png` | 턱을 괴고 미소 지으며 이야기를 듣는 동자승, 작은 찻잔 | 768×768, 투명 배경, 얼굴과 손 완전 포함 |
| `scene-lotus-pond.webp` | 호흡: 맑은 하늘과 연못. 가운데 호흡 UI 자리 확보 | 1200×800, 글씨 없음, 160KB 목표 |
| `moktak-wood-cushion.png` | 자연스러운 나뭇결·금빛 문양의 목탁을 방석 위에, 목탁채 제외 | 1024×1024, 투명 배경, 가장자리 8% 여백 |
| `moktak-mallet.png` | 별도 회전 가능한 목탁채. 손잡이 끝을 회전축으로 사용 | 512×768, 투명 배경, 세로 방향 |
| `scene-writing-desk.webp` | 한지·먹·붓·책갈피, 필사 영역은 밝고 비워 두기 | 1200×800, 문자 없음 |
| `scene-travel-scroll.webp` | 지도와 여행 가방·두루마리. 실제 장소를 암시하는 임의 건축물 제외 | 1200×800, 글씨 없음 |
| `scene-cloud-garden.webp` | 마음 정원: 흐린 구름과 꽃. 맑음/흐림 레이어 분리 | 1200×800 배경 + 1200×400 투명 구름 PNG |
| `scene-moon-wish.webp` | 달빛·등불·소원함. 글쓰기 영역은 따뜻한 밝은 종이색 | 1200×800, 글씨 없음 |
| `scene-bead-lotus.webp` | 염주와 연꽃 중심의 평온한 정원 | 1200×800, 카운터 자리 비움 |
| `scene-wish-workshop.webp` | 한지·붉은 인주·금빛 끈이 있는 공방 | 1200×800, 부적 내용은 HTML/Canvas에서 렌더링 |
| `scene-rhythm-playground.webp` | 라벤더·코랄·청록 음악 놀이 공간. 게임 레인과 패드 자리 비움 | 1200×800, 140KB 목표, 번쩍이는 효과 금지 |
| `scene-music-room.webp` | 헤드폰·작은 스피커·LP와 산 풍경 | 1200×800, 컨트롤과 제목 자리 비움 |
| `vinyl-record.png` | 동자승과 분리해 회전하는 LP 소품 | 768×768, 투명 배경, 정확한 중앙 회전축 |

PNG 원본을 보관하고 UI 배경은 WebP로 제공한다. 모바일에서도 얼굴·소품이 잘리지 않도록 안전 영역 10%를 남기고, 텍스트·버튼을 이미지에 넣지 않는다. 장소별 제작 검토 목록은 [place-illustration-review.md](place-illustration-review.md)에 있다. 공식 참고 자료 확인과 사용 권한 검토 전에는 실제 장소의 대표 그림으로 등록하지 않는다.
