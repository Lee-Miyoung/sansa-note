# 산사노트 통합 수정 · 2026-10-26

기준 main: `2d3c2b958b9e21aec8112463ca07977ada9f7e96`. 운영 Firebase/Storage에 테스트 쓰기를 하지 않았다. 모든 계정·권한·위치 수정 검사는 로컬 파일을 제공하는 HTTPS 라우팅과 Firebase/Kakao 모의 응답으로 수행했다. 실제 Google 로그인 팝업, Firebase 운영 규칙 허용 여부와 실기기 GPS는 자동화로 확인한 것으로 간주하지 않는다.

## 변경과 저장 범위

- 공개 읽기/검색/지도/24편 이야기/음악은 유지하고 개인 기록 추가 동작은 Google 회원으로 제한했다. 로그인 취소 시 기존 화면을 유지하고 로그인 후 명시적인 계속하기 버튼을 제공한다.
- 계정 전환 시 기존 실시간 구독을 해제하고 메모리·개인 뷰·입력 초안을 비운다. history 복원은 같은 계정의 스냅샷만 허용한다. 과거 게스트 기록은 삭제하거나 자동 합치지 않으며 별도 ZIP 보존 내보내기를 제공한다.
- IndexedDB 이름·버전·사진 키와 기존 MY 번호를 유지했다. 새 사진 Blob/미리보기는 로그인 UID별 브라우저에 저장한다. Firebase에 새 사진이나 base64는 올리지 않는다. 기존 클라우드 사진은 읽고 같은 뷰어에서 본다. 사용자가 삭제를 확인했을 때만 해당 사진을 삭제한다.
- 절/산 상세·앨범은 같은 사진 목록과 기존 lightbox를 사용한다. 세로 스크롤은 길게 누르기를 취소하고 전체 Blob URL은 현재/양옆 최대 3개로 제한한다. ZIP 명시적 저장, 공유 취소, 무결성 검사, 같은 UID 복원과 중복 보존을 유지했다.
- 개인 카드 6개 테마와 수집 장식은 기존 수채화 8개를 재사용했다. 새 이미지 생성/대형 이미지 추가가 없다. 기본 그림에 이미 있는 무념스님을 중복 합성하지 않으며 내 사진 배경에는 테마별 무념스님을 합성한다. 테마·배경·장식의 작은 메타데이터만 `users/<uid>/personalTempleCards/<id>`에 저장하고 사진 ID는 기기에만 저장한다. MY 번호와 공식 108 도감은 유지한다.
- 개인 추가 사찰 위치는 해당 사용자 `destinations/<id>/personalLocation` 및 `locationEdits`에만 저장한다. 정확한 검색 결과 선택·마커 이동·최종 확인을 거친다. 기존 방문·MY·사진·소감은 수정하지 않고 공식 108 지점은 이 화면에서 변경하지 않는다.
- `music/catalog.json`은 기존 실제 파일 5곡만 등록했다. 사찰별 새 음원은 미제공이므로 어떤 절에도 임의 연결하지 않았다. 음악방·기존 플레이리스트·등록된 곡의 절 상세 버튼은 기존 `playlistAudio`/`SONGS`를 공유한다. 신규 등록 시 고유 musicId, templeId, title, artist, audioUrl, coverUrl, duration, published 및 rightsConfirmed:true를 확인해야 한다. 홈에서는 음원을 미리 요청하지 않는다.
- 24편 내용·이미지·회차 ID·진행 키는 변경하지 않았다. 공개 읽기는 가능하고 신규 개인 진행/카드/메모 저장만 회원으로 제한한다. 과거 게스트 기록은 읽기와 보존을 유지하며 회원 기록에 섞지 않는다.
- 캐시는 v19로 갱신했으며 IndexedDB/사용자 localStorage를 초기화하는 코드는 추가하지 않았다.

## 시작 성능

390×844, CPU 4배 제한, SDK 모의 응답 2초 지연, 3회씩의 통제 실험이다. 실제 휴대폰 통신망 수치가 아니다. 기준 HTML/SW와 현재 HTML/SW를 비교했고 다른 공통 파일은 현재 파일을 사용했다. 병렬 실행에 따른 편차도 있어 절대 속도 개선으로 단정하지 않는다.

- FCP 중앙값: 976ms → 652ms, DOMContentLoaded: 1811ms → 1136ms, LCP: 4624ms → 4284ms.
- worker 설치 요청: 20 → 20개, 4,958,821 → 4,960,786바이트. 음원/영상 요청은 양쪽 모두 0개.
- 홈 회차 본문/전체 이미지 사전 로드 없음, 음악방 등록 파일 외 새 대형 미디어 없음.
- 검색 결과 진입 모의 검사에서 지연 네트워크 중 캐시 화면 열기·뒤늦은 응답 갱신·오프라인 재진입·기존 로컬 기록 보존을 통과했다.

상세 출력은 checks.txt와 perf-before.json/perf-after.json에 기록했다. 테스트 이미지와 ZIP에는 모의 데이터만 사용했다.
