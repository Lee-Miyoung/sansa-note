# 사찰 수채화 대표 이미지

## 현재 범위와 남은 작업

최신 카탈로그는 111곳입니다. **실제 참고 사진을 확보·육안 비교한 7곳만 수채화를 적용했습니다. 전체 완료가 아닙니다.** 나머지 104곳은 다른 절 그림을 대입하지 않고 기존 표시 방식을 유지합니다. 특히 갓바위(선본사)는 목포 갓바위 사진과 혼동하지 않아야 합니다. 해당 절의 참고 사진 다운로드가 403으로 막혔고 추가 다운로드 승인 요청도 중단되어 미완료입니다. 자료 없는 절의 추상 배경 대체 여부는 사용자 확인을 요청했습니다. 확정되지 않은 건축물을 생성해 채우지 않았습니다.

[전체 111곳 목록](coverage.csv)의 `ready`만 실제 파일이 있고, `reference_required` 경로는 향후 제작 **예정 경로**입니다. 미존재 경로를 앱에 연결하지 않았습니다. 다음 제작도 실제 사찰 사진과 권리 확인 → 개별 수채화 생성 → 참고 사진 비교 → WebP 압축 → 정확한 ID/지역 등록 순서로 진행합니다. 제작 사양은 3:2, 원화 1536×1024, 배포 768×512 WebP 160,000바이트 미만, 가장자리 주요 전각 잘림 방지, 글씨·배지 없음입니다.

## 연결과 표시

`scripts/temple-covers.js`의 명시적 `temple:이름` + 정확한 지역으로 연결합니다. 개인 Firebase 키를 이 ID로 바꾸지 않습니다. 다른 지역의 같은 이름, 비슷한 이름, 산에는 연결하지 않습니다. `manifest.json`에는 ID/지역/경로/크기/SHA-256/참고 사진/작가/라이선스/가공 내역을 기록합니다.

등록된 수채화는 외부 사진 검색·자동 교체에서 제외합니다. 3:2 썸네일, 12px 모서리, 모바일 두 행 텍스트/버튼 배치, 지연 로딩과 고정 크기를 사용합니다. 로컬 이미지 실패 시 한 번 재시도하고 다른 절 사진으로 바꾸지 않습니다. 설명 배지나 준비 중 문구는 카드에 올리지 않습니다. 저작권 표기는 카드 밖의 **이미지 이용 안내** 링크와 `images/temple-covers/CREDITS.html`에 유지합니다.

상세 화면의 실제 사진 검색/출처/사용자 사진/앨범은 보존합니다. `firstPhotoUrl`, `fetchCoverPhotoNow`, Firebase 설정, 기존 카탈로그 원본과 사용자 데이터 구조는 변경하지 않습니다.
