# 몰입형 법당 · 상단 가림 대응과 창작 입장음

기준: 최신 main `0ec799f8caf86cbcc51fc1a135ea49a3ce7fcb54`. 이전 변경을 다시 적용하지 않고 이번 수정만 추가했습니다.

## 화면과 참여

- 산사·법당·마음 쉬어가기·고민 처방 창을 브라우저의 **실제 보이는 영역(VisualViewport)** 높이와 위치에 맞춥니다. 주소창·키보드로 높이나 위쪽 오프셋이 바뀌면 다시 계산합니다.
- 고정된 제목/닫기 영역, 내부 스크롤, 안전 영역 패딩을 분리했습니다. 초기 시트 이동 애니메이션과 중복 패딩을 제거했고 같은 계열의 창이 겹쳐 가리지 않게 정리합니다. 다른 법당/내 속도 전환은 상시 유틸리티 행에 남겼습니다.
- 일반 모바일/PC 화면에서는 이전 상단 잘림이 바로 재현되지 않았습니다. 보이는 영역을 420px/상단 오프셋 90px로 변경한 모의 조건에서 제목·닫기가 영역 안에 남는지 검사했습니다. 사용자의 실제 Safari 기기를 검사했다는 뜻은 아닙니다.
- 법당은 짙은 녹색의 공간, 금빛 현재 단계, 실제 완료 단계의 체크로 대비를 키웠습니다. 입장·숨 고르기·삼배·염불·발원·마무리의 흐름을 그림 아래에 배치합니다.
- 직접 누른 삼배/108배만 참여 꽃과 숫자로 표시합니다. 타이머나 캐릭터 동작이 횟수를 올리지 않습니다. 모르는 공동 참여 인원은 표시하지 않습니다. 실시간 집계의 기존 비활성 상태는 변경하지 않았습니다.
- 첫 화면의 긴 순서는 접어두고 ‘종을 울리고, 예불에 입장’을 중심 행동으로 배치했습니다. 무음 입장과 도움말도 유지합니다. 실제 염불을 재생하는 단계에서는 안내보다 플레이어를 더 또렷하게 표시합니다.

## 새 소리

[마음을 여는 종 · 산사노트 창작](../../../audio/dharma-hall/original-opening.mp3) · **28.029초** · 산사노트 · CC BY 4.0

금속 종의 배음과 나무 타격음을 직접 수학적으로 합성한 오리지널입니다. 실제 낭송이나 특정 사찰의 의식을 새로 확보한 것으로 표시하지 않습니다. 사용자 버튼으로만 1회 시작하며 반복하지 않습니다. 염불 단계에서는 기존 김용배의 실제 ‘염불소리1’로 단일 플레이어가 전환합니다. 다른 법당의 미확보 정근 상태도 유지합니다.

측정: MP3 디코딩 후 **-25.45 LUFS**, true peak **-13.46 dBTP**. [분석](audio-analysis.json). 사람의 스피커/이어폰 청취 검사를 했다는 뜻은 아닙니다. [권리·제작 설명](../../../audio/dharma-hall/ORIGINAL.md), [재현 코드](../../../tools/create-opening-sound.py).

## 실제 실행한 검사

- `tests/monastery-stage.cjs`: 320×568, 390×844, 820×1180, 1440×900에서 제목·닫기 가시성, 자동 재생 없음, 새 파일 실제 디코딩/길이, 창작 음원 유형, 삼배 체크·꽃의 정확한 계수, 실제 염불 전환/정지, 창 중복 해제, 사용자 쓰기 없음. VisualViewport 높이/오프셋 모의 및 약사전 정근 미확보 시 무음도 검사.
- `tests/hall-experience.cjs`: 네 화면 크기 핵심 행동·도움말·직접 참여·청취 시간·108배·정시 입장 회귀 검사 통과.
- `tests/online-sansa-browser.cjs`: 여섯 법당과 자유/정시 예불·전환·퇴장·발원 비전송 검사 통과.
- `tests/hall-scheduled-entry.cjs`, `tests/practice-studio.cjs`: 정시 시작 전 대기/직접 참여, 기존 음원 네 개, 관리자 타임라인/음량/초안/모의 게시 검사 통과.
- `tests/dharma-hall.cjs`, `tests/navigation-history.cjs`, `tests/unified-music.cjs`: 기존 엔진·내비게이션·음악 플레이어 회귀 검사 결과는 최종 커밋 검증에 포함합니다.
- `tests/online-sansa.cjs`, `tests/practice-config.cjs`: 설정·음원 허용 범위·기존 규칙 경로 정적 비교 통과.

모든 브라우저 조작 검사는 로컬 Chromium + 모의 Firebase입니다. 실기기 Safari/WebKit·스피커/이어폰 검사는 미수행입니다. 운영 Firebase·개인 기록·순례·사진·GPS·카드·권한에는 변경을 배포하지 않습니다.
