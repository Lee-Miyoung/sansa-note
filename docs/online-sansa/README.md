최신 확장과 정좌·고민 선택·공동 참여 준비 상태는 [온라인 산사 완성도 개선 보고](completion/README.md)를 참고하세요.

이전 참여형 화면 변경은 [온라인 법당 UI/UX 수정 보고](GUIDED-UX.md)를 참고하세요. 그림 위 안내 분리·자유 기도 행동 진행·108배 자세 전환은 이 후속 변경이 기준입니다.

## 3. 음원과 권리

기존에 확보·확인한 공유마당 **김용배의 염불소리1·절 법당 종소리·목탁3**, **한국저작권위원회의 사찰 풍경소리**를 유지했습니다. 모두 **CC BY 4.0**이며 원본 출처·라이선스·저작자·변경 내역·해시를 표시합니다. [전체 기록](../../audio/dharma-hall/SOURCES.md), [음량 분석](../practice-studio/audio-analysis.json).

염불 파일은 약 119초이며 원문 내용과 낭송자 신원은 특정하지 않았습니다. 종은 약 24초의 끝 울림을 보존하고 기본 시퀀스에 25초/30초 여유를 둡니다. 일반 염불의 허용 전각은 대웅전뿐입니다. 다른 전각의 정근 녹음 5종은 미확보입니다. 공유마당에서 이름으로 검색하고 우선 후보 상세 페이지를 살폈으나 조사한 후보들은 녹음이 아니었습니다. [검색 기록](audio-search.json), [후보 상세 확인](audio-candidates.json). 검색 전체를 망라했다거나 특정 정근이 존재하지 않는다고 주장하지 않습니다.

## 4. 자유 기도와 정시 예불

- 자유 기도: 3분·5분·10분은 머무름 예상 시간이며 강제 종료하지 않습니다. 무제한 선택도 제공합니다. 기본 무음, 여섯 단계를 내 속도로 진행하고 건너뛴 행동은 완료하지 않습니다. 방석에 앉은 뒤 합장·한 배·앉아서 대체 참여·선택 발원. 클릭한 실제 참여만 계수합니다. 자동 리듬과 동작 미리보기는 횟수를 올리지 않습니다.
- 정시 안내: 사용자 제안 시간표를 Asia/Seoul로 계산합니다. 대웅전 매일 07:00/20:00, 문수 월/목 20:30, 관음 화/금 20:30, 약사 수/일 20:30, 극락 매일 21:00. 지장 일정은 관리자 추가를 지원합니다.
- 시작 시각·남은 시간·길이·실제 음원 또는 준비 상태·출처·자유 기도 전환을 표시합니다. 실제 실시간 법회로 표시하지 않습니다.
- 중간 입장은 시작 시각에 대한 절대 경과로 현재 단계에 진입합니다. 재생을 멈춰도 프로그램 시계는 계속되며, 재개 시 현재 위치에 맞춥니다. 지난 합장·절을 참여로 세지 않습니다. 녹음 로딩 후 시간 오차도 현재 시계에 맞춥니다.
- Firebase의 `.info/serverTimeOffset`을 받을 수 있으면 시각을 보정합니다. 그렇지 않으면 ‘기기 시계 기준’이라고 표시합니다. 외부 시각을 받지 못한 기기의 시계 오차까지 검증했다고 주장하지 않습니다.
- 머무른 시간은 보이는 상태에서 진행한 시간만 누적하고, 정시 프로그램 전체 길이와 구분합니다. 숨김·다른 오디오 재생·퇴장 시 음원을 멈춥니다. 발원 입력은 메모리에만 두고 퇴장 시 지우며, 내비게이션 세션 저장에서도 제외했습니다.

`tests/online-sansa.cjs`는 한국시간 요일/자정/다음 시작/중간 입장/예약 공개/중단/음력 출처 누락을 검사합니다. `tests/online-sansa-browser.cjs`는 네 화면 크기에서 여섯 공간과 실제 참여, 자유 기도 4종, 늦은 정시 입장, 일시정지 후 현재 위치, 과거 활동 비계수, 선택 발원 비전송·비저장을 검사합니다. 모두 통과했습니다. 가상 시계 검사는 실제 스님이 진행하는 법회를 검증하는 것이 아닙니다.

## 5. 온라인 산사 운영실

관리자 페이지 `/admin-practice/#sansaStudio`와 관리자용 설정 메뉴에 연결했습니다. 기존의 검증된 Google 관리자 인증과 전용 비캐시 서비스워커를 사용합니다.

전각별 이름·설명·발원·본존 설명·도상·검토된 이미지·음원 목록·공개 상태, 한국시간 요일/시각/진행 시간/예약 공개/운영 중단을 편집합니다. 본존과 부처/보살 구분, 이미지의 전각 연결은 검증합니다.

타임라인은 전체 예불의 구간 바, 재생 위치, 시작·끝 이동 슬라이더, 파일 오프셋·끝, 음원 시작·무념스님 동작·자막·말풍선 시점, 자동 전환·행동 대기를 제공합니다. 실제 플레이어로 구간 반복과 현재 시점 찍기를 하며 미리보기 일시정지를 지원합니다. 전체 예불 시계와 음원 파일 시계를 분리하여 표시합니다.

초안은 `users/{adminUid}/practiceStudio/onlineSansa/draft`, 이력은 같은 개인 경로의 `history`, 공개 운영본은 `shared/onlineSansa/current`입니다. 미리보기·음원 확인·모바일 확인 후 revision 조건부 쓰기를 하고 서버를 재조회해야 성공으로 표시합니다. 이전 버전은 새 초안으로 복원하고 다시 검증·게시합니다. 기본 사용자 데이터에 자동 마이그레이션·삭제·초기화는 없습니다.

모의 Firebase 브라우저 검사에서 여섯 전각 편집, 타임라인 시작점 이동, 지장 일정 추가, 구간 미리보기, 개인 초안, CAS 게시·재조회, 이전 버전 복원 초안이 통과했습니다. **운영 서버 규칙 적용과 실제 Google 관리자 권한 검증은 별개이며 아직 완료하지 않았습니다.**

새 `shared.onlineSansa` 규칙과 확장한 시퀀스 필드 규칙은 [기존 규칙을 보존하는 추가안](../practice-studio/shared-rules-additions.json)에 있습니다. 테스트용 병합본을 운영 규칙 전체로 덮어쓰지 마세요. 저장소에 문서화된 기존 규칙과 관련 없는 모든 경로가 그대로인 정적 비교 검사는 통과했습니다. 에뮬레이터 실행은 다운로드 정책 차단으로 미실행입니다.

## 6. 즉문즉답 개선과 검증

대표 원고 30건, 변형·오타·부정문 18건, 모호한 입력 4건, 복합 고민 1건, 위기 3건 검사가 통과했습니다. 기존 1,000개 사례는 933건 매칭·47건 확인 질문·20건 안전 안내 결과를 유지했습니다. 별도 40개 표현·부정·안전 검사도 통과했습니다.

이번 요청의 ‘엄마가 아픈데 병원비 때문에 힘들어요’, ‘남편이 제 말을 들어주지 않아요’도 추가 검사합니다. 의료비 단어가 부정된 경우 부모 간섭으로 올바르게 연결하고, 실제 환자를 어머니로 바꿔 말하지 않도록 했습니다. 모욕을 분노 조절로 돌리지 않습니다. 분류 일치를 보편적인 답변 품질 보증이나 사람의 검수 완료로 간주하지 않습니다. 실제 고민은 명시적 동의·로그인·보내기 전에는 관리자에게 수집하지 않습니다.

## 8. 미완료와 사유

- 특정 법당용 정근 5종과 대웅전의 원문이 확인된 삼귀의 독송: 적합한 녹음·권리·내용 확인 미완료. 준비 상태를 표시하고 무음으로 이용합니다.
- 운영 Firebase의 새 규칙 게시: 주입된 자격 증명으로 규칙 읽기를 시도했으나 인증에 실패했고 관리 권한이 확인되지 않았습니다. 기존 사용자 데이터와 규칙에는 쓰지 않았습니다.
- 새 서버 규칙 에뮬레이터: `storage.googleapis.com` 다운로드가 현재 환경 정책에서 차단되어 실행하지 못했습니다. 필요한 도메인 추가를 환경 초안에 저장했으나 실제 실행 정책에는 아직 적용되지 않았습니다.
- iPhone Safari/갤럭시 실기기: 미수행. Chromium에서 320·390·768·1440px, 추가 비밀도감 820px를 검사했습니다. 실제 단말·스피커·이어폰 청취 검증으로 대신 주장하지 않습니다.
- 음력 행사: 검증된 음력→양력 변환 출처와 확정 시각을 담는 특별 일정 구조만 준비했습니다. 변환기를 새로 만들거나 가상의 행사를 공개하지 않았습니다.
- 불교문화: 기존 백과 출처·대표 도상을 활용한 창작 그림이며 전문가 감수·특정 사찰 일치 검증은 미수행입니다.

새 관리자 초안/게시/복원 기능은 코드와 모의 검사를 갖췄지만, 서버 규칙이 적용되기 전에는 운영 쓰기가 거부될 수 있습니다. UI는 이를 성공으로 보고하지 않습니다. 정적 여섯 전각·기본 시간표·자유 기도는 서버 쓰기 없이 동작합니다.

## 9. 커밋과 재현

## 10. GitHub Pages와 운영 확인

기존 GitHub Pages의 `main` 배포 방식을 유지합니다. 원격 반영 성공, Pages 빌드 성공, 실제 운영 응답은 각각 구분하여 최종 보고합니다. 현재 환경의 `sansanote.com`과 `api.github.com` 접근 허용은 초안에 저장했으며 아직 실행 정책에는 적용되지 않았습니다. 확인되지 않은 Pages 성공을 완료로 표시하지 않습니다.
