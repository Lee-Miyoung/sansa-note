# 온라인 법당 참여형 UI/UX 수정 보고 · 2026-11-01

## 1. 화면 구조

법당 이름 → 깨끗한 법당 그림과 방석 → 별도 안내 패널로 재구성했습니다. PC는 좌우 배치, 모바일은 그림 아래 패널입니다. 현재 단계·단계 수·지금 할 일·핵심 행동·다음 단계·시간 안내는 패널 상단에 모았습니다. 음원 설정과 단계 선택은 보조 영역입니다.

그림 안에서 무념스님·대사·상태·설명을 모두 분리했습니다. 무념스님은 안내 패널의 작은 초상으로 함께합니다. 그림 위에는 텍스트 없는 방석 표시만 남습니다.

## 2. 수정 전후

| 수정 전 | 수정 후 |
| --- | --- |
| 그림 위 말풍선·상태·여러 행동 버튼 | 그림과 안내 분리, 핵심 행동 1개·대체 행동 1개 |
| 자유 기도가 선택 시간에 자동 종료 | 내 속도로 여섯 단계 진행, 예상 시간이 지나도 자동 완료 없음 |
| 무엇을 해야 하는지 모호한 합장·절 버튼 | 합장 설명, 첫 번째/두 번째/세 번째 절 문구, 직접 계수 |
| 진행 시간과 실제 참여가 혼동됨 | 머무른 시간·직접 동작·실제 청취·발원을 따로 요약 |
| 캐릭터 회전·세로 축소로 절을 표현 | 회전·축소 키프레임 제거, 실제 그린 자세 전환 |

## 3. 그림과 불상

여섯 공간을 각각 더 정교한 산사노트 전용 AI 수채화 수정본으로 제작했습니다. 석가모니불의 촉지인, 아미타불의 선정인, 관세음보살의 보관·정병, 문수보살의 사자·경책, 약사여래의 약그릇, 지장보살의 석장·보주 등 기존 대표 도상 구별을 보존했습니다. 목재·단청·등·마루·방석의 질감을 다듬었습니다.

운영 파일은 `images/online-sansa/{id}-refined.webp` 및 `-refined-small.webp`입니다. 옛 이미지는 삭제하지 않았습니다. 운영 설정이 옛 기본 파일명을 가리켜도 표시할 때 수정본으로 연결하며, 운영자가 별도로 선택한 이미지는 유지합니다. Firebase 설정 자체를 고치지 않습니다.

자세 2개를 포함한 WebP 14개 합계 **1,861,770바이트**. [파일별 해시·크기](guided-ux-images.json). 특정 사찰의 복원 그림이나 전문가 감수 완료로 표시하지 않습니다.

## 4. 108배 동작

누워 보이던 원인인 `rotate(32deg)`·`scaleY(.68)` 및 반복 회전 키프레임을 원본 CSS에서도 제거했습니다. 합장 → 무릎 앉기 → 무릎을 접고 몸 낮추기 → 몸 세우기 → 합장으로 돌아오는 짧은 자세 전환을 사용합니다. 몸 전체를 회전시키지 않습니다. 동작 감소 설정에서는 정적인 합장 자세를 사용합니다.

안내 간격은 직접 세기·보통·천천히·아주 천천히입니다. 안내 동작은 자동 계수하지 않습니다. 실제 클릭만 1회씩 세며, 합장 대체 참여도 따로 기록합니다. 중간 종료 시 실제 수행 횟수만 요약합니다.

## 5. 초보 안내

첫 입장의 ‘처음 오셨나요?’에 다섯 가지 참여 순서와 설명 보기/바로 시작 버튼을 추가했습니다. 상시 `? 도움말`에서 합장·삼배·염불·발원을 설명합니다. 도움말 안에 키보드 포커스를 유지하고 Escape로 도움말만 닫습니다.

별도 사람 대상 사용성 조사는 수행하지 않았습니다. 초보 문구·필수 정보의 표시·화면 조작은 자동 브라우저 검사와 화면 캡처 확인으로 검증했습니다.

## 6. 자유 기도와 정시 예불

자유 기도는 입장과 합장 → 숨 고르기 → 삼배 → 염불 듣기 → 발원 → 마무리 여섯 단계입니다. 합장·숨 고르기·직접 삼배·다음 선택·발원·종료 버튼으로만 넘어갑니다. 삼배 도중 시간이 지나도 횟수나 단계는 올라가지 않습니다. 원하는 단계로 이동할 수 있고 건너뛴 행동은 완료로 세지 않습니다. 입장 화면의 시간 선택은 ‘머무름 예상 시간’으로 명확히 표시합니다.

정시 예불은 한국시간 시작 시각에 따른 기존 절대 시계·운영 시퀀스를 보존합니다. 중간 입장·일시정지 후에도 현재 단계와 남은 시간이 맞춰집니다. 지나간 합장·삼배·듣기는 완료로 채우지 않습니다. 관리자 미리보기의 시퀀스 문구·자막 구간·음원/안내 시점 도구도 유지합니다.

## 7. 음원 정보

기존 단일 플레이어를 재사용하며 음원 제목·유형·현재/전체 시간·실제 재생 상태·연결 단계·저작자·라이선스·출처·음량·재생/일시정지/정지를 표시합니다. 입장은 무음이고 사용자 선택으로만 소리를 시작합니다. 108배로 전환할 때도 기본 무음입니다.

실제 재생된 염불 파일의 시간 증가만 청취 시간에 누적합니다. 탐색으로 건너뛴 시간·일시정지·화면 숨김은 청취로 올리지 않습니다. 없는 음원은 ‘무음 진행 중’, 시간은 `— / —`로 표시합니다. 다른 플레이리스트와 중복 재생하지 않습니다.

음원은 새로 합성하거나 바꾸지 않았습니다. 김용배의 **염불소리1·절 법당 종소리·목탁3**, 한국저작권위원회의 **사찰 풍경소리**, 모두 공유마당 **CC BY 4.0**입니다. [출처·조건·변경 내역](../../audio/dharma-hall/SOURCES.md). 실제 염불 파일 길이는 약 119초입니다. 다섯 법당의 특정 정근은 여전히 미확보이며 무음으로 안내합니다.

## 10. 커밋

최종 응답의 새 SHA로 확인합니다. `git show --stat <SHA>` 및 위 Node 명령으로 재현할 수 있습니다. 빌드나 신규 패키지 설치는 필요하지 않습니다.

## 11. 배포와 데이터 보존

기존 GitHub Pages의 main 배포 경로를 사용합니다. 원격 push와 실제 사이트 게시 확인은 구분해 최종 응답에 기록합니다. 네트워크 정책 때문에 사이트/API 응답을 확인하지 못한 경우 성공했다고 보고하지 않습니다.

Firebase 규칙·사용자 데이터·108순례·수호카드·사진·기록에는 삭제·초기화·마이그레이션이 없습니다. 발원 텍스트는 전송하거나 저장하지 않으며 퇴장 시 지웁니다. 새 공유 설정 규칙의 기존 미적용 문제는 그대로이며, 이번 변경의 자유 기도는 서버 쓰기 없이 동작합니다.
