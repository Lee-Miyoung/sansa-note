- 여섯 법당마다 **별도로 제작한 낮은 눈높이 정좌 원화**로 전환됩니다. 기존 입장 그림을 확대하거나 이동시키는 방식이 아닙니다. 방석 표시는 정좌 후 사라지고 정좌 상태를 안내합니다.

- 직접 삼배·108배·앉아서 대체 참여·동작 감소 설정·실제 참여 요약을 유지합니다. 자유 기도는 사용자 행동을 기다리며 타이머로 완료하지 않습니다.
- 정시 안내 예불의 시작 전 대기와 **시작 시각 이후 직접 누르는 참여 버튼**을 추가했습니다. 공동 시계는 유지하며 지나간 행동은 개인 완료로 세지 않습니다.
- 기존 4개 검증 음원을 그대로 사용하며 실제 제목·길이·출처·재생 상태·정지를 표시합니다. 관리자 단계별 음량 슬라이더를 실제 오디오 엔진에 연결했습니다. 음원 시계와 프로그램 시계는 분리되어 있습니다.
- 마음고민처방은 12개 분류의 선택 화면과 직접 입력 탭을 제공합니다. 기존 113개 답변에 직접 연결하며 불확실한 입력은 확인 질문을 합니다.
- ‘도움이 되었어요’는 이 기기에서만 표시하고, ‘제 상황과 달라요’는 틀린 점과 추가 설명을 받습니다. 무작위로 같은 답변을 반복하지 않습니다. 위로/현실 정리/관점 전환/짧은 답변을 선택할 수 있습니다. 원래 상황과 안전 우선 분기는 유지합니다.
- 신규 20개 검증 사례를 추가하고 기존 30개 대표 사례·1,000개 추가 사례·1,974개 기존 예시를 보존했습니다. 새 20개와 변형 10개가 통과했고, 기존 1,000개의 933 매칭/47 확인/20 안전 결과도 유지했습니다.
- 예불 종료 후 더 머물기·고민 처방·기존 마음 기록·다른 법당으로 선택 이동합니다. 치료 대체나 유료 기능 강제 연결은 없습니다.

## 그림·동작의 실제 상태

기존 입장 원화의 대표 도상(촉지인·선정인·관세음보살 보관/정병·문수보살 사자/경책·약사여래 약그릇·지장보살 석장/보주)을 참고한 **산사노트 AI 창작 원화**입니다. 정좌 그림은 낮아진 시선·불단 전면·천장/기둥의 투시·아래쪽에 일부만 보이는 방석으로 구도를 다시 그렸습니다. 원본 PNG는 작업 환경의 `/workspace/generated_images`에 보존하고 1200px/640px WebP를 운영 파일로 연결했습니다.

| 방식 | 이번 선택 근거 |
| --- | --- |
| 독립 WebP 포즈 | 기존 캐릭터와 투명 배경을 유지하고 동작 시점·감소 설정을 오디오와 독립적으로 제어할 수 있어 선택 |
| 투명 WebM | 실제 연속 영상 원본이 없고 Safari 호환성을 검증하지 못해 적용하지 않음 |
| MP4 | 투명 배경이 없고 실제 영상 제작 자료가 없어 적용하지 않음 |

위 비교는 설계 판단이며 영상 형식별 실기기 성능 벤치마크를 수행했다는 뜻이 아닙니다. 영상 생성 도구로 MP4/WebM을 제작한 것은 아닙니다. 요청에서 허용한 **독립 포즈 기반 프레임 애니메이션**을 적용했습니다. 정지 이미지를 동영상이라고 보고하지 않습니다. 동작 파일에 소리는 없고 기존 오디오 엔진만 음향을 담당합니다. 연꽃 공양도 기존 무념스님 원화를 사용합니다.

문화 참고 링크는 기존 한국민족문화대백과사전 출처를 유지했습니다. 새로 직접 열어 확인하려 했으나 도메인 정책의 CONNECT 403으로 10개 링크 확인이 막혔습니다([기록](culture-reference-check.json)). 특정 실존 불상의 복제·정확한 복원·새 전문가 감수를 완료했다고 주장하지 않습니다.

## 운영 활성화가 남은 항목

1. **실시간 참여 인원:** 코드/별도 서버 모듈/규칙 초안/모의 검사는 준비됐지만 운영 서버의 기존 상위 규칙을 읽을 관리자 자격 증명이 없습니다. 에뮬레이터도 다운로드 정책으로 실행하지 못했습니다. `PRODUCTION_READY=false`로 유지하며 새 서버 경로를 읽거나 쓰지 않습니다. 인원수는 ‘참여 인원 확인 중’으로 표시합니다. [배포 전 실제 검증 조건](PRESENCE.md).
2. **WebKit:** 설치를 시도했으나 `cdn.playwright.dev`와 `playwright.download.prss.microsoft.com`이 403으로 차단되었습니다. iPhone/iPad 화면 크기의 WebKit 검사를 완료하지 않았습니다.
3. **Firebase 규칙 에뮬레이터:** demo 프로젝트 실행을 시도했으나 `storage.googleapis.com`의 JAR 다운로드 실패로 규칙 검사를 수행하지 못했습니다. 규칙 초안을 운영 전체 규칙으로 덮어쓰지 않았습니다.
4. **실기기/청취:** iPhone Safari·iPad·갤럭시 실기기 및 스피커/이어폰 청취 검사는 미수행입니다. 자동 브라우저 검증과 사람 대상 사용성 조사도 구분합니다.
5. **특정 정근 5종/불교문화 전문 감수:** 위 자료·감수 미완료 상태를 유지합니다.
