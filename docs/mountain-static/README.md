# 산 대표 수채화 통일·정적 표시 및 마지막 콘텐츠 제작

기준 main `8beccfd`, 확인일 2026-10-27. 동일 버전 재배포가 아니라 실제 표시 코드·방문팁·원화 4점(원본과 썸네일 8개 WebP)을 추가한 작업입니다.

| 항목 | 기존 완료 | 신규 완료 | 최종 완료 | 미완료 |
|---|---:|---:|---:|---:|
| 사찰 방문팁 | 110 | 1 | 111/111 | 0 |
| 사찰 개별 수채화 | 110 | 1 | 111/111 | 0 |
| 산 개별 수채화 | 97 | 3 | 100/100 | 0 |

이 수치는 파일 생성·장소 ID 연결·데코딩 및 문헌 특징 대조를 기준으로 합니다. 이번 4점은 자료에 나온 특징을 반영한 **창작 수채화**입니다. 원 공식 사이트의 직접 본문 열람이나 사진과의 정밀 실경 대조를 마친 수치로 해석하면 안 됩니다. 불확실한 전각 배치·폭포 형상은 제작 대상에서 제외했습니다.

## 원인과 수정

- `renderAutoCoverPhotos`가 산의 기존 `coverPhotos`를 우선했고, 해당 배열이 비었을 때만 수채화를 선택했습니다. `cardCoverMedia`도 옛 사진을 수채화 위에 추가할 수 있었습니다. 목록과 상세가 다른 대표물을 보여 준 실제 원인입니다.
- `mountainPlaceholderHtml`의 `.cover-placeholder` 클래스는 그림 로딩 뒤에도 유지됐습니다. index의 `.cover-placeholder::after`가 `sansaShimmer 1.5s infinite`를 실행해 빛이 반복해서 지나갔습니다.
- 산 그림 요소에서 로딩 전용 클래스를 제거했습니다. 애니메이션을 다른 레이어로 덮어 숨기지 않았습니다. 산 그림과 그 img만 정적인 속성을 적용하고, GPS·연꽃 카드·축하 효과는 그대로 두었습니다.
- 목록·메인 카드·상세는 동일한 `SansaPlaceIdentity` 고유 ID의 수채화를 사용합니다. 목록은 같은 작품의 썸네일, 상세는 원본 → 같은 썸네일 → 중립 안내 순입니다. 외부 사진은 대표 영역에 넣지 않습니다. 알 수 없는 사용자 산도 중립 안내로 표시합니다.
- 산 대표 영역에 필요 없는 외부 사진 검색·이미지 감시 타이머 진입을 중단했습니다. 늦게 온 예전 사진 콜백도 같은 그림 DOM·src를 교체하지 않습니다. 사진 앨범과 저장된 옛 `coverPhotos` 데이터는 변경하거나 삭제하지 않았습니다.
- 서비스워커 캐시 v23과 공개 파일 버전을 갱신했습니다. 홈페이지는 팁·출처 전체 JSON과 그림 원본을 미리 읽지 않습니다.

## 검증 및 데이터 보호

실제 실행 로그·화면·결과는 validation에 기록합니다. PC Chromium 1440, 갤럭시 크기 Chromium 412, 아이폰 크기 WebKit 390, 아이패드 크기 WebKit 820. 실제 기기는 사용하지 않았습니다.

- `tests/mountain-static.cjs`: 산 100곳 목록 썸네일/상세 원본 일치, 옛 사진 우선 문제, 정적 CSS·가상요소, 두 번의 옛 shimmer 주기를 넘긴 픽셀 동일성, 반복 콜백의 DOM/src 불변, 실패 시 원본→동일 썸네일→중립 안내, 재열기/새로고침, 사용자 사진·메모·GPS·원격 쓰기 보존.
- `tests/catalog-complete.cjs`: 전체 211장소·별도 사용자 2곳의 목록/상세 디코딩, 방문팁 111건, 동명 장소 구분, 초기 미리 로딩 방지 및 사용자 기록 보존.
- `tests/catalog-preservation.py`: 이전 완료 팁·그림 메타데이터·파일 해시 보존 및 공개 레지스트리 JS gzip 증가 예산.
- `tests/catalog-image-audit.py`: 211작품 파일 디코딩·원본/썸네일 대응·중복 및 좌우반전 유사도.

Firebase 운영 데이터·규칙·GPS·사용자 사진/IndexedDB 스키마·순례번호·도감 저장 형식·MY·음악·관리자 코드는 변경하지 않았습니다. 검사는 모의 계정/데이터로 수행하고 운영 사용자 데이터에는 쓰지 않았습니다.

### 검사 집계

전체 카탈로그는 네 화면 크기 모두 111개 팁·211개 작품 디코딩·213개 목록 배치를 통과했습니다. 사용자 장소 2곳은 중립 대표 안내입니다. 기존 완료 팁 110건·작품 레코드 207건·커버 디렉터리의 기존 WebP 404개와 과거 기준의 317개 파일은 해시가 같습니다. 211작품의 원본 22,155쌍과 좌우 반전 22,155쌍 비교에서 유사 후보 0개(dHash 256비트 거리 22 이하).

초기 공개 레지스트리 JS의 gzip 추정 합계는 직전 10,182 → 10,419바이트(237바이트 증가)입니다. 실기기 회선 속도 측정값은 아닙니다. 사진·로그인·GPS·서비스워커·기존 비밀도감 회귀 검사는 모두 통과했습니다.

산 대표 전용 검사는 네 환경 모두 **100/100 목록·100/100 상세**, 픽셀 불변·반복 DOM 교체 0·썸네일/중립 대체·재열기·새로고침 통과, 페이지 오류 0건입니다. 그림이 다른 창에 가려진 상태가 아닌 실제 표시 중인 대표 영역을 검사했습니다. [실행 결과와 화면](validation/).
