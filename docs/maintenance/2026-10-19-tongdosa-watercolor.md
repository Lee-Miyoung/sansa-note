# 통도사 본문·카드 수채화 교체

사용자가 보낸 3번 장면 화면에서 확인한 문제는 누락된 파일이 아니라 기존 1·2화와 다른 단순 SVG 도형 삽화였다. 앞선 로딩 진단만으로는 이 그림체 문제를 해결하지 못했다.

본문 12장면과 카드 3장을 기존 무념스님 캐릭터·표지·불국사 그림을 참고한 AI 창작 수채화로 다시 제작했다. 금강계단을 다층 석탑과 혼동한 생성 결과는 수정했다. 생성 원본 PNG는 `/workspace/generated_images/`에 보존하고 배포에는 압축 WebP만 넣었다. 그림은 역사 현장이나 유물의 정확한 복원도가 아니다. 기존 전승 구분 및 출처 확인 상태는 유지했다.

변경 범위는 통도사 이미지, 이미지 경로·설명, 해당 content.js 버전, 그림 안내 및 관련 회귀 검사 경로다. 본문 문장·퀴즈·카드 ID/조건·저장 키·공유 렌더러·홈 HTML·홈 목록·기존 1·2화 콘텐츠는 유지했다. Firebase 운영 데이터에는 접근하거나 쓰지 않았다.

휴대폰은 기존 공통 렌더러가 작은 WebP부터 요청한다. 본문 작은 그림은 장당 약 42~68KB이고 카드 작은 그림은 98KB 미만이다. 활성 파일 전체 합계 약 5.2MB는 모든 크기·표지까지 더한 저장 용량이며 초기 전송량이 아니다. 그림을 홈페이지나 회차 시작 때 모두 미리 받지 않는다. 새 디렉터리로 캐시된 도형 삽화와 주소를 구분했고, 기존 주소는 이미 열어 둔 화면을 위해 남겼다.

검사: `tests/atlas-home-catalog.cjs`의 실제 3회차·가상 12회차 홈 비선로딩/이동, `tests/tongdosa-mobile.cjs`의 WebKit 390/820px 전체 이야기/6문제/3카드/기록 복원/기존 회차 기록 보존, `tests/atlas-art-recovery.cjs`의 Chromium/WebKit 이미지 오류 복구, `tests/tongdosa-transport.cjs`의 실제 서비스워커 전환. 3번 장면을 390/858px에서 직접 캡처해 그림체·디코딩도 확인했다. 실제 사용자 아이폰 검증과 원문 대조 대기 상태는 별개다.
