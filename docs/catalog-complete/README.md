## 변경 내용

- 방문팁을 ID별 경량 JSON으로 분리하고 상세 화면에서 한 번만 불러옵니다. 각 검증 항목은 2개 개별 카드, 실제 열람한 자료의 URL·확인일·원본 해시·대조 키워드를 기록했습니다. 불확실한 요금·시간·이동 수치는 쓰지 않았습니다.
- 기존 34곳 원화와 같은 사찰의 비밀도감 13곳 원화를 보존·재사용했습니다. 사찰 56곳, 산 56곳에 새 창작 수채화를 등록했습니다. 칠갑산 시안 1개는 참고 사진이 산세 검증에 부족해 등록하지 않았습니다.
- 새 작품은 1200×800 WebP와 480×320 썸네일을 나누었습니다. 신규 원본 목표 상한 185KB, 썸네일 상한 55KB. 기존 비밀도감 원본은 변경하지 않았습니다. 기존 33개 원화에도 별도의 480×320 목록용 썸네일을 만들어 원본 다운로드를 줄였습니다. 목록은 지연 로딩하며 상세 원본은 즉시 요청합니다.
- 동명 장소는 지역·소재지·정규 ID로 구분합니다. 기존 사용자 ID를 바꾸거나 마이그레이션하지 않습니다. 반복되던 공통 숲길 대신 미완료 장소명을 적은 중립적 안내 이미지를 사용합니다.
- 서비스워커 캐시 버전 v21, 공개 JS 요청 버전을 갱신했습니다. 초기 화면에서 방문팁 원고·전체 작품 감사 자료·비밀도감 본문·음악을 미리 요청하지 않는지 검사했습니다.
