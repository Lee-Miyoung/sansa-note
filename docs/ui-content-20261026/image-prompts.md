# 산 수채화 시안 제작 사양

공통: 3:2 가로 구도, 크림 종이 질감의 부드러운 수채화, 세이지·숲 초록·따뜻한 갈색, 글자·배지·워터마크·건물·인물 없음. 실제 현장 복원도로 간주하지 않는 감성 풍경. image_gen으로 텍스트에서 생성한 뒤 리사이즈·메타데이터 제거·WebP 압축만 수행했다. 외부 사찰/산 사진을 생성 도구에 전달하거나 운영에 포함하지 않았다.

| 대상 | 구도와 모티프 | 확인 상태 |
|---|---|---|
| 가야산(경상) | 회색 암릉이 모인 정상과 초여름 숲, 겹치는 산자락, 앞쪽 산길 | 기존 산 소개에 근거한 개념 시안, 실제 사진 대조 미완료 |
| 가지산 | 왼쪽 바위 봉우리에서 오른쪽으로 이어지는 영남알프스 능선, 봄 숲과 바윗길 | 동일 |
| 간월산 | 둥근 억새 능선과 넓은 안부, 가을 은빛·금빛 풀, 능선의 걷는 길 | 동일 |
| 감악산(수도권) | 숲이 우거진 계곡을 가로지르는 작은 보행 현수교와 낮은 바위 능선 | 동일. 실제 교량 구조·길이 복원 아님 |
| 계룡산 | 가로로 이어지는 낮은 바위 능선과 소나무, 늦봄 숲과 옅은 안개 | 동일 |

공식 참고 서버 조회는 권한 범위 밖 실행으로도 재시도했지만 403 응답이 유지되었다. 실제 사진을 확인한 것처럼 표시하지 않고, 각 이미지의 manifest.referenceStatus를 conceptual-not-photo-verified로 남겼다. 세부 위치·지형 대조와 나머지 산의 개별 대표 그림 제작은 후속 확인 항목이다.
