# UI·콘텐츠 통합 개선 · 2026-10-26

기준 main: `a1d97c7f89a68dc35bca763aef0a98336d3a9462`. 운영 Firebase·Storage에 테스트 쓰기를 하지 않았다. 검사에는 로컬 HTTPS 라우팅과 모의 Firebase/Kakao 응답을 사용했다.

## 변경

- 사진 관리 버튼이 화면 높이 829px로 늘어나 사진을 덮는 현상을 기준 화면에서 재현했다. 상시 버튼을 없애고 기존 lightbox를 3열 그리드로 정리했다. 좌우 원형 화살표는 사진 밖 양옆, 제목·번호는 하단, 확대·닫기는 상단에 둔다. 가로/세로 비율, 스와이프, 방향키, 확대, 길게 누르기·우클릭·Shift+F10 관리, 삭제 확인, 포커스 복귀와 감소 동작 설정을 유지했다. 관리 메뉴의 Escape는 뷰어까지 닫지 않도록 기존 navigation의 선점과 충돌도 해결했다.
- 가야산(경상)·가지산·간월산·감악산(수도권)·계룡산의 서로 다른 수채화 5종과 480×320 썸네일을 추가했다. 원화는 768×512 WebP이며 각 94KB 미만이다. **이 그림은 기존 산 설명의 특징을 바탕으로 한 감성 그림이다. 공식 참고 서버가 403을 반환하여 실제 사진 대조는 미완료이며, 현장 대표 모습을 검증 완료한 그림으로 표시하지 않는다.** alt/title, 산 상세의 문구, 별도 CREDITS와 manifest에 구분했다. 사용자의 실제 사진과 기존 정상 coverPhotos는 우선 유지한다. 동일 이름의 다른 지역에 자동 연결하지 않으며 나머지 산으로 임의 복제하지 않는다.
- 무위사는 제014화에서 이미 검토한 대표 수채화를 목록·상세에 재사용했다. 해인사의 기존 개별 그림은 유지했다. 백련사·백담사·미황사는 확인된 개별 원화가 없어 다른 절 그림을 복사하지 않고 중립 숲길을 유지했다. 전체 111개 사찰 매핑과 34개 개별 이미지의 SHA256, 깨짐 fallback을 확인한다. 기존 24편 원고·그림·ID를 바꾸지 않았다.
- 방문 전 한눈 팁은 14곳의 구별되는 관람 지점·동선·추천 중심으로 짧게 나누었다. 공통 새벽/저녁 예불 시간과 반복 주차 안내를 제거했다. 지정되지 않은 장소에는 정보를 확인하지 못했다는 짧은 안내만 둔다. 가격·운행 시각·주차 혼잡도 등 변동 정보를 새로 단정하지 않았다. 미황사의 배경은 달마산으로 바로잡았고, 기존 사용자 소감/visitorTip 데이터는 덮어쓰지 않는다. 역사·건축 항목은 기존 회차 자료와 저장소 정보를 재사용했으며 외부 관광 안내를 새로 열람 완료했다고 주장하지 않는다.
- 공식 108순례를 메인으로 유지하고 그 카드 안에 작은 개인 도감 설명과 진입을 넣었다. 전체 도감 버튼에 108 수호카드를 명시하고 개인 도감은 직접 추가한 절의 기념카드임을 구분했다. 개인 도감은 홈과 마이페이지에서 열 수 있다. 목록 제목을 밀어내던 큰 개인 도감 버튼은 제거했다. MY 번호 발급·소장·디자인 저장 구조와 공식 108 컬렉션은 변경하지 않았다.
- 음악방을 기존 playlistOverlay 안의 두 번째 탭으로 옮기고 홈/설정에 따로 붙은 음악방 버튼은 제거했다. 하나의 playlistAudio/SONGS, 기존 5곡과 가사·순서·싱크·공유 링크를 재사용한다. 사찰 음원이 없는데 기존 5곡을 사찰 노래처럼 반복 등록하지 않는다. 사찰 탭의 현재 빈 상태는 그대로 알리고, 신규 사찰 음원 연동은 모의 등록 자료로만 검사했다. WebKit에서 첫 탭을 프로그램으로 열었을 때 창이 화면 아래에 머무는 sheet 애니메이션 충돌은 음악 창에 한해 제거했다.
- 검색 중 이전 목록 스크롤 때문에 첫 결과가 상단 도구 아래 가려지지 않도록 검색 시 목록을 처음부터 보여준다. 새 대형 홈 배너·영상·외부 라이브러리는 추가하지 않았다. 이미지와 회차 본문을 홈에서 한꺼번에 읽지 않는다. 서비스 워커는 v20이며 사용자 IndexedDB/localStorage 초기화 코드는 추가하지 않았다.
