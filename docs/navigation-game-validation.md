# 2026-10-17 디자인 정리·뒤로가기·게임 수정 검증

## 변경 내용

- `scripts/navigation.js`: 내부 탐색의 History API 소유자를 하나로 통합했다. 기존 index의 중복 popstate 세 곳과 history 쓰기를 제거했다. 모달·감정 결과·발원문 작성·부적 미리보기·검색 상세·108 도감 탭·수호카드 상세·게임 순위를 구분한다. 검색/필터/스크롤/작성 내용을 복원하며 브라우저 Forward와 외부 이전 페이지를 유지한다. 필사 문서의 뒤로가기는 실제 방문 이력으로 돌아간다.
- 발원문 초안은 사용자별 별도 sessionStorage 키에 보관하고, 저장이 성공하면 해당 초안을 비운다. 탐색 상태 복원은 Firebase 기록을 되돌리거나 쓰지 않는다.
- `scripts/game-viewport.js`, `styles/game-viewport.css`: 게임에만 visualViewport·안전 영역·가로세로 회전 대응을 적용했다. 여섯 조작 버튼을 표시 공간 안에 배치하고 작은 높이에서는 부가 정보만 접는다. 순위 접근 버튼은 유지했다. 게임 종료 시 viewport 메타와 일반 페이지 확대/스크롤을 복원한다. 종료 후 지연 회전 콜백이 게임을 재개하는 문제도 차단했다. 게임 진행 저장 형식은 그대로 사용한다.
- `styles/wellness.css`: 메뉴 카드의 반복 산·사찰·꽃 장식을 제거하고 차 받침·물결·방석·종이·달·리듬·레코드 등 기능별 간결한 소품을 적용했다. 기존의 작은 카드 높이를 유지했다.
- 새 동자승 12개 포즈는 회색·세이지·베이지 복장과 동일한 얼굴 스타일을 사용한다. 홈 필사와 제목 옆 필사 캐릭터는 다른 자세다. 원본 이미지와 기존 기능은 보존했다. 제작 사양은 [이미지 계획](navigation-game-art-plan.md)에 있다.
- `scripts/meditation-sounds.js`: 자체 Web Audio 합성 종소리 네 종류, 미리 듣기, 음량, 호흡 연동 선택을 추가했다. 사용자 동작 이후 재생하며 기존 호흡 타이머와 배경음은 유지했다.
- 서비스 워커 캐시 버전과 관련 정적 파일 버전을 갱신했다. 사용자 localStorage/Firebase/IndexedDB를 초기화하는 코드는 추가하지 않았다.

## 검증 한계

- WebKit 브라우저 설치가 자동 승인 검토에서 거부됐다. 반환 사유는 `denied`였다. 실제 iPhone Safari 하단 뒤로가기·주소창 동작·오디오와 Galaxy/iPad 실기기 동작은 미확인이다. 해당 항목을 실기기 통과로 주장하지 않는다.
- 테스트는 외부 SDK/네트워크를 차단하거나 fixture로 대체한다. 실제 Firebase 계정 로그인·서버 순위 저장·GPS 현장 인증·커뮤니티 서버 쓰기를 실행하지 않았다. 기존 연동 코드를 보존했으나 실서비스 계정별 E2E 검증은 별도다.
- 뒤로가기 회귀는 위에 적은 주요 경로와 공통 모달 처리를 검증했다. 앱의 모든 계정 조건·모든 팝업 조합을 전수 검사한 것은 아니다.
