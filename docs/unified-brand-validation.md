# 전체 브랜드 통합·오류 수정 결과

최신 기준: `36efa44` 이후의 소스와 사용자 제공 「산사노트 마음 쉬어가기」 시안. 이전 검증 문서는 당시 작업 기록이며 현재 상태는 이 문서를 우선한다.

마이페이지는 구형 `feature-*.png` 장식을 제거하고 기존 `images/brand/monks/`의 미소·걷기·독서·기도·명상·놀람과 `symbols/lotus.png`를 사용한다. 절 제목에는 `card-suggest-temple.webp`, 산 제목에는 `card-breath-mountain.webp`를 사용한다. 기존 파일은 삭제하지 않았다.

추가로 제작하면 좋은 전용 찻집/공방/서재/음악방 그림과 별도 목탁채 파일 사양은 [wellness-art-specifications.md](wellness-art-specifications.md)를 따른다. 기존 소품을 조합한 UI는 구현했고, 미제작 원화를 제작 완료로 보고하지 않는다. 실제 장소별 그림은 [place-illustration-review.md](place-illustration-review.md)의 공식 자료 확인 후에만 제작한다.

## 원인과 수정

1. 원형 심볼에는 `sansaBrandDiscSpin` 애니메이션 이름만 있고 keyframes 정의가 없었다. 16초 회전 정의를 추가하고 실제 transform 값이 시간에 따라 달라지는지 검사했다. 글자 로고는 회전하지 않는다. `prefers-reduced-motion: reduce`에서 애니메이션이 none이 되는지도 검사했다.
2. 카탈로그의 `#catalogOverlay .catalog-thumb > *`가 `position:static!important`여서 대체 그림 다음에 사진이 배치되고 overflow로 가려졌다. absolute/inset 0으로 고쳐 사진과 대체 그림이 같은 칸을 공유하게 했다. 기존 검증에서 단순 디코딩 성공만 보면 놓칠 수 있는 오류라 실제 이미지 사각형이 사진 칸 안에 있고 opacity 1인지 검사하는 테스트를 추가했다.
3. 필사 번호와 `/108`이 좁은 카드에서 한 줄 폭을 초과할 수 있었다. 숫자/분모를 grid로 구분하고 여백·폰트 크기를 조정했다. 진행률 108/108도 별도로 검사했다.
4. 마이페이지의 오래된 pseudo 이미지 34개 규칙이 남아 있었다. 해당 그림 참조 규칙을 제거하고 현재 브랜드 이미지 노드를 넣었다. 기존 onclick과 기능은 유지했다.
5. 이전 CSS가 새 글자 크기를 덮어쓰는 부분을 확인하고 실제 계산값을 검사했다. 홈 카드 제목 모바일 18px 이상, 설명 PC 15px, 마이페이지 제목 18px·설명 14~15px, 공통 설명 15px·일반 본문 16px·버튼 16px, 필사 주요 안내 15~16px를 적용했다. 좁은 내비게이션 보조 메뉴는 14px, 고유 게임 HUD는 기존 크기를 유지한다.

## 검증한 내용

테스트는 Playwright + 시스템 Chromium, 격리된 저장소 및 로컬 최신 파일로 실행했다. 실 사용자 Firebase 쓰기 작업은 하지 않았다.

- 320·390·768·1024·1440px: 실제 로고 회전, 동작 줄이기, 감정 얼굴 9개 로딩·서로 다른 sprite 위치·9개 모두 기존 장소 추천 결과 연결, 마이페이지 버튼 영역·구형 그림 제거·18px 제목 확인.
- 같은 5개 화면 폭: 절/산 제목의 한국 사찰·산 그림 전환, 사진 없는 대체 화면, 장소 검색.
- 같은 5개 화면 폭: 필사 1·99·100·108과 완료 108/108, 번호/분모가 카드 안에 있는지, 가로 넘침 여부, 안내 글씨 크기, 기존 필사 내용·완료 기록 보존.
- 320·375·390·430·768·1440px: 홈 11개 그림 로딩, 글자/캐릭터 충돌·가로 넘침 검사. 모바일 일반 카드 높이는 72px 유지. 마음 쉬어가기 4개는 18px 제목을 읽을 수 있도록 2열 구성. 그리드 높이 합계 448px로 과거의 584px보다 작다(영역 제목·영역 간 여백 제외).
- 320·390·768·1440px: 내부 모달 10개와 별도 필사 페이지 배치·닫기 검사.
- 390·1440px: 실제 코스·커뮤니티·마이페이지 내비게이션, 지도 API 불가 시 안내 화면, 108 순례 수호카드 도감, 현장 인증 기록 화면 진입 확인.
- 390·1440px: 목탁 클릭/Enter·카운터 저장, 호흡·닫기, 처방, 염불 카운터 저장, 발원문 저장, 부적 종이/문양·Canvas 결과, 곡 선택, 게임 패드·최고점 보존, 필사 이어쓰기 회귀 검사.

## 실제 확인하지 못한 항목

- 실제 아이폰 Safari/WebKit, 아이패드/갤럭시 기기에서의 실행. 현재 설치된 브라우저는 Chromium이며 화면 폭·터치 컨텍스트로 검증했다.
- 운영 Firebase 계정 로그인·사용자 데이터 쓰기, 현장 GPS 판정, 운영 랭킹 등록. 기존 처리 경로·저장 구조·계산/재생/게임 로직을 유지했다.
- 외부 사진 제공 서버의 운영 사용자 네트워크 성공률. 해당 서버는 이 작업 환경의 앞선 실요청에서 403을 반환했다. 이번에 사진 표시를 가리는 CSS 원인은 고쳤으나 서버 접근 성공을 보장하지 않는다. 실패 시 일반 수채화임을 밝히고 장소명을 별도로 표시한다.
- 실제 기기의 음질·음량 및 자동재생 정책. 기존 소리 코드는 유지했다.
