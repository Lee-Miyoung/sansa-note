## 홈과 공개 상태

기존 108순례 바로 위의 작은 가로 목록을 유지합니다. 선택한 시즌의10개 회차만 DOM에 만들고 가까운 작은 썸네일만 불러옵니다. 본문·문제·장면·카드는 홈에서 미리 로드하지 않습니다. 큰 배너와 무거운 라이브러리는 추가하지 않았습니다. 썸네일은 contain으로 전체 구도를 보여 줍니다. 높이는 검증한320~1440px 화면에서294px 이하입니다.

시즌 선택은 별도 로컬 키 sansaAtlasHomeSeason_v1에만 기억합니다. 배포 승인된 시즌2는 seasons.json의 homePublished:true로 홈 표시를 확인합니다. Firebase 연결 지연·권한 문제만으로 공개 완료된 시즌 버튼을 숨기지 않습니다. 기존 관리자 공개 경로 shared/secretAtlasPublication/haeinsa-001의 명시적 비공개는 전체 홈 목록을 계속 숨깁니다. 설정 없음(null)의 기존 기본값 true는 유지하며, 비공개는 전체 홈 목록을 숨깁니다. 공개 메타데이터도 확인되지 않은 시즌만 시즌1로 돌아갑니다. 이미 확인한 값은 일시적 오류에도 유지합니다. 직접 회차 주소는 기존처럼 공개 주소입니다. 새 DB 경로나 운영 규칙을 만들지 않았습니다.
