# 제2화 불국사 및 공통 읽기 개선

## 콘텐츠

- 주소: /atlas/bulguksa/, 제목: **불국사 — 두 탑이 품은 천 년의 이야기**.
- 별도 12장면/6문제/3카드, 16종 수채화(표지·12장면·3카드)의 원본/모바일 WebP 32개.
- 석가탑/다보탑의 조형 차이 → 무영탑 전설 → 1966년 석가탑 수리 중 다라니경 발견 → 전쟁 피해·중건·보존·1995년 세계유산 등재로 연결합니다.
- 아사달·아사녀와 영지 이야기는 장면 5~6에서 전설로 밝힙니다. 실제 인물의 확인된 행적으로 표현하지 않습니다. 세계 최초 인쇄물, 특정 제작 장소/정확한 제작 연대는 단정하지 않습니다.
- 불국사 이야기 삽화는 앞선 사용자 지시의 실제 유산 형태 조건에 따라 별도로 제작했습니다. 참고 사진의 원저작자/라이선스와 가공 내역은 /atlas/bulguksa/CREDITS.html 및 이미지 manifest에 기록합니다. 사진을 쓰지 않는 새 **사찰 대표 일러스트** 시스템과 구분합니다. 지도/굿즈를 새로 만들지 않았습니다.

해인사 본문은 2755→1876자(약 32% 감소)로 정리했습니다. 기존 12장면 순서·그림·6문제·3카드 ID/내용과 출처는 그대로입니다. 어려운 말은 짧게 풀고 핵심어를 강조합니다. 무념스님 대사는 두 장면에만 둡니다. 두 편 모두 세 단락과 짧은 핵심 상자를 사용합니다.

## 공통 UI와 안전

- 홈의 기존 비밀도감 자리는 가로 scroll-snap 목록으로 바꿉니다. 첫 화면 해인사, 다음 불국사. 네이티브 터치 스와이프/좌우 버튼/페이지 점/키보드 화살표를 지원하고 자동 넘김은 하지 않습니다.
- 기존 공개 플래그 shared/secretAtlasPublication/haeinsa-001은 홈 이야기 목록 전체(1·2화)의 표시를 제어합니다. 새 규칙이나 두 번째 공개 경로를 만들지 않습니다. 관리자 안내도 목록 전체에 대한 설정임을 명시합니다. 직접 URL은 계속 공개입니다.
- 두 편의 장면 이동은 1~12 range로 제공하며 손을 놓아 변경을 확정할 때 이동합니다. 44px 조작 영역/미리보기/현재 번호/키보드 이동과 이전·다음을 유지합니다.
- 이동 막대로 건너뛰는 것만으로 카드가 지급되지는 않습니다. 기존처럼 네 장면의 읽기 완료 기록이 쌓이면 해당 부의 카드를 얻습니다.
- 로컬 키와 서버 경로의 haeinsa-001은 그대로, 불국사는 bulguksa-002입니다. 저장 스키마 version 1과 기존 merge/normalize 방식은 유지하며 마이그레이션·삭제·초기화하지 않습니다.
- 서버는 현재 계정의 users/{uid}/secretAtlas/{현재 에피소드}만 쓰고 destinations는 해당 절의 기존 현장 인증 확인을 위해 읽기만 합니다. 해인사 인증이 불국사 인장으로 쓰이지 않습니다.
- /atlas/sw.js의 기존 네트워크 전용 처리를 두 페이지가 공유합니다. 새 페이지가 루트 앱의 계정 응답 캐시를 쓰지 않도록 부모 atlas 범위의 워커를 명시합니다. 메인 워커는 바꾸지 않습니다.
- 운영 Firebase 규칙·프로젝트 설정·관리자 인증 방식·108 수호카드·순례앨범·게임·지도 데이터는 변경하지 않습니다.

## 근거와 검증 한계

UNESCO/국가유산 공식 링크와 확인 범위를 자료 영역에 유지합니다. 이 환경에서 공식 역사 원문 일부는 CONNECT 403으로 차단되어 전체 원문 대조 완료로 표시하지 않았습니다. 모든 관련 출처의 pending 상태를 유지합니다. 사진 메타데이터와 건축물 형태 검토가 역사 원고 원문 대조 완료를 의미하지는 않습니다.

tests/atlas-episodes.cjs는 6개 크기에서 2편 각각 12장면/실제 range 키보드 이동/6문제 정답 선택/3카드·중복 방지/그림 디코딩/감상·새로고침/뒤로가기·닫기, 두 편의 저장 키 분리, 홈 좌우·점·터치 스와이프와 페이지 넘침을 검사합니다. 모의 계정 A/B의 두 경로와 기존 방문/108 fixture 보존도 검사합니다.

GitHub Actions의 **전체 통합 규칙** 데모 에뮬레이터에는 두 에피소드의 A/B 저장·조회·상호 접근 차단, 기존 해인사 노트 불변, 관리자 읽기 유지 검사를 추가했습니다. 규칙 JSON은 수정하지 않았습니다. 실제 Google 로그인/운영 데이터 저장/물리 iOS·Galaxy 단말 검사는 수행하지 못했습니다.
