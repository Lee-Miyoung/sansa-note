## 관리자 공개 설정

서버의 새 경로를 인증 없이 조회한 결과는 여전히 HTTP 401 `Permission denied`였습니다. 현재 운영 규칙에 필요한 경로가 없어 버튼을 활성화할 수 없으며, UI만 바꿔 이 권한을 우회하지 않습니다.

클라이언트는 기존 `ADMIN_EMAIL`과 `isAdminUser()`를 재사용합니다. 권한 오류/네트워크 실패/오프라인/응답 지연을 구분하고, 저장 승인 및 재조회 일치 전에는 완료를 표시하지 않습니다. 응답 지연은 실패나 성공으로 단정하지 않고 대기 상태로 유지합니다. 계정 전환 후 늦게 도착한 응답은 이전 세션의 UI를 바꾸지 않습니다.

관리자 화면에서 ‘최초 1회 설정’을 펼치면 **rules.shared 안에 추가할 secretAtlasPublication 항목만** 복사할 수 있습니다. 기존 전체 규칙을 덮어쓰는 복사가 아닙니다. [적용 절차](README.md#운영자-최초-1회-설정)와 원래 검증된 최소 규칙 조각은 유지하며 운영 규칙은 적용하지 않았습니다. 홈에서 숨김은 직접 주소의 접근 차단이 아니라는 설명을 명시했습니다.
