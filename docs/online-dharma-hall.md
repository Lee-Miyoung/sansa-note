# 무념스님의 온라인 법당

홈의 ‘작은 수행 · 재미’ 아래 온라인 법당 버튼에서 로그인 없이 입장합니다. 입장할 때 기존 플레이리스트와 명상 소리를 중단하고 무음으로 시작합니다.

## 구현한 흐름

- 고요히 머물기: 시간 제한 없이 무음으로 머무는 모드.
- 작은 예불: 합장 30초 → 3배 안내 60초 → 조용히 귀 기울이기 150초 → 발원과 마무리 60초. 현재 염불 파일이 없으므로 해당 단계에 준비 중이라는 문구를 표시합니다.
- 108배 마음 수행: 직접 세기 또는 8·12·20초 안내 간격. 되돌리기·일시정지·정지. 횟수는 108에서 멈춥니다. 기록은 메모리에만 두며 Firebase·순례 기록·기존 게스트 기록에 쓰지 않습니다.
- 무념스님이 예불의 3배 단계와 자동 108배 안내에서 몸을 낮추는 동작을 합니다. 동작 줄이기 설정에서는 움직이지 않습니다.
- 백그라운드 전환·다른 소리 재생 시 일시정지, 법당 퇴장 시 초기화. 다른 창으로 이동해도 예불 시간이 계속 흐르지 않도록 합니다.
- 한국 목조 법당의 불단·불상·연꽃 대좌·기둥·단청·연등·마루·방석을 배치한 정적인 전용 SVG 그림. 특정 사찰 재현물이 아닙니다. 기존 무념스님 이미지를 함께 사용합니다.

## 아직 완료하지 않은 항목

실제 염불·목탁·종소리 파일은 아직 없으며 재생 가능한 후보로 노출하지 않습니다. 공유마당 상세 페이지는 실행 환경의 HTTPS CONNECT 정책에서 403으로 차단되었습니다. 환경 초안의 도메인 허용을 실행 환경에 적용한 뒤 권리 확인·다운로드·오디오 검증을 재개해야 합니다. [후보 및 권리 확인 절차](../audio/dharma-hall/SOURCES.md)를 참고하세요.

전통 악기 오리지널 곡 제작, 염불·종·목탁 음량 균형, 실제 녹음의 잔향과 꼬리 보존, 반복 경계, iPhone Safari 실기기·스마트폰 스피커·이어폰 청취 검증은 완료하지 않았습니다. SVG는 초기 공간 일러스트이며 세밀한 수채화 원화의 후속 개선 여지가 있습니다.

새 수행 기록 저장 기능은 추가하지 않았습니다. 향후 저장 기능을 추가할 때 기존 `SansaSession.require`의 Google 로그인 정책을 따라야 하며 순례 데이터 구조를 재사용하거나 변경하지 않습니다.

## 개발 및 확인

빌드·패키지 설치 없이 저장소 루트에서 `python3 -m http.server 8000 --bind 0.0.0.0`으로 실행합니다. 현재 환경에는 Node 24, Python 3, Playwright, Chromium, ffmpeg가 설치되어 있습니다. 브라우저와 HTTP 서버가 샌드박스 소켓 제한에 걸리는 경우 실행 도구의 권한 승격을 사용합니다.

검사 명령:

```sh
node --check scripts/dharma-hall.js
node tests/dharma-hall.cjs
node tests/calm-design-audio.cjs
node tests/unified-music.cjs
git diff --check
```

법당 검사는 로컬 파일과 Firebase 모의 응답을 사용하는 Chromium 테스트입니다. 320·390·768·1440px에서 무음 입장, 미검증 음원 제외, 전체 5분 단계, 정지·재개, 안내 간격과 수동 계수, 108배 상한, 퇴장 정지, Firebase 쓰기 없음, 화면 폭 맞춤을 확인합니다. 기존 실제 플레이리스트의 시간 진행과 법당 입장 시 중단도 검사합니다. 브라우저 가상 시계로 검증하며 실제 사찰 음원이나 iPhone 실기기 검증을 대신하지 않습니다.
