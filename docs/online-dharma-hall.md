# 무념스님의 온라인 법당 · 참여형 체험

홈 ‘작은 수행 · 재미’의 온라인 법당에서 로그인 없이 입장합니다. 기본은 무음이며, 기존 명상·플레이리스트는 입장할 때 중단합니다. 순례·Firebase 설정·카드·사진 데이터와 기존 기록은 변경하지 않았습니다.

## 사용자의 흐름

- 저해상도 모바일용 49KB / 데스크톱용 175KB 전용 수채화 배경. 목조 기둥·단청·연등·불단·마루·중앙 방석을 배치한 가상 공간입니다. 원화는 AI로 생성했으며 특정 사찰 실경을 복제하거나 재현했다고 표시하지 않습니다. 기존 SVG는 삭제하지 않고 보존했습니다.
- 내 자리 표시, 무념스님 말풍선, 지금 할 행동, 연꽃 공양, 삼배 참여 흔적을 표시합니다. 과도한 점수·순위·반짝임은 없습니다.
- 고요히 머물기: 시간 제한 없이 선택한 소리 또는 무음.
- 작은 예불: 합장 25초 → 호흡 15초 → 삼배 60초 → 염불 120초 → 발원 30초 → 마무리 종 30초 → 고요 20초. 단계마다 행동·안내·진행 시간·자막·말풍선·음원 시작을 따로 관리합니다.
- 삼배는 한 배씩 직접 누르거나 느린 3배 안내를 선택합니다. 108배는 직접 세기 / 8·12·20초 간격, 되돌리기와 108회 상한을 지원합니다. 무리하지 않고 앉아서 합장해도 참여할 수 있습니다.
- 음향은 소리 없이 텍스트 / 염불 중심 / 아주 조용한 예불 / 108배 리듬형. 입장만으로 재생하지 않습니다. 아주 조용한 예불은 같은 녹음의 재생 gain을 낮춥니다.
- 음원 제목·종류·실제 파일 길이·현재 시간·탐색 바·재생/일시정지/정지·음량을 표시합니다. 음원 일시정지 시 예불도 멈추어 싱크를 유지합니다. 탐색은 현재 단계 범위 안에서 예불 시계를 함께 조절합니다.
- 실제 염불 녹음 119초가 끝나면 반복하지 않고 해당 단계의 남은 여백을 고요히 유지합니다. 최초 종 단계 25초와 마무리 종 단계 30초는 24초 종 파일의 끝 울림을 보존합니다. 목탁은 강제로 매번 재시작하거나 무한 반복하지 않습니다.
- 숨김·다른 소리 재생·퇴장 시 정지 또는 일시정지. 횟수와 참여 흔적은 이번 방문의 메모리 상태만 사용합니다. 동작 줄이기 설정에서는 절 동작을 끕니다.

## 실제 사용 음원

김용배의 **염불소리1**, **절 법당 종소리**, **목탁3**, 한국저작권위원회의 **사찰 풍경소리**를 연결했습니다. 모두 공유마당 상세 페이지의 **CC BY 4.0**를 확인했습니다. [출처·권리 근거·변환 내역](../audio/dharma-hall/SOURCES.md)과 [분석 수치](practice-studio/audio-analysis.json)를 참고하세요.

확보한 염불 재생 파일은 약 1분 59초입니다. 이전 안내의 7분 19초 파일과 같다고 주장하지 않습니다. 선운사 저녁예불은 권리 미확인으로 사용하지 않았습니다. 전통 악기 곡은 제작·추가하지 않았습니다.

## 검증과 한계

`node tests/dharma-hall.cjs`는 320·390·768·1440px의 기본 무음·7단계·삼배·108배·일시정지·완료·퇴장·화면 맞춤을 검사합니다. `node tests/practice-studio.cjs`는 네 MP3의 실제 디코딩과 시간 진행, HTTP Range 탐색, 재생 충돌 방지, 관리자 미리보기·임시 저장·검수·최종 반영을 모의 Firebase로 검사합니다. `node tests/calm-design-audio.cjs`, `node tests/unified-music.cjs`는 기존 명상·음악을 검사합니다.

자동 분석에서 클리핑은 없었습니다. iPhone Safari 실기기, 스마트폰 스피커·이어폰의 체감 음질·음량 균형은 아직 검증하지 않았습니다. 관리자 실제 Google 인증·운영 서버 권한·운영 반영도 모의 검사와 구분합니다. 새 서버 규칙은 별도 적용이 필요합니다. [운영실 설명](practice-studio/README.md)을 참고하세요.
