## 기존 항목과의 연결

기존 원문 배열은 삭제하거나 덮어쓰지 않습니다. 별도 표시 모델이 이름을 기준으로 확장 설명을 연결하고, 검색에는 원래 이름·한자·기존 설명도 포함합니다. 겹치는 항목을 새 카드로 중복 추가하지 않습니다. 원래 문장이 지나치게 단순했던 부처님·보살님 항목은 같은 카드에 검토한 확장 요약을 우선 표시하고, 원래 데이터는 연결 상태로 유지합니다. 특히 보살을 모두 ‘부처가 되기 직전 단계’로 일반화하지 않도록 안내했습니다.

## UI·검색·속도

전체 / 부처님 / 보살님 / 법당과 불상 / 불교 개념의 작은 분류 탭을 추가했습니다. 검색은 현재 분류 안에서 이름·한자·별칭·관련 전각·설명·관련 용어를 함께 찾습니다. 전체 탭에서는 전체 사전을 검색합니다. 관련 용어를 누르면 전체 분류에서 해당 말을 찾습니다.

부처·보살 비교, 과거·현재·미래/삼신불/삼존불 분류, 법당과 대표 봉안 대상 7행 표는 작은 접이식 안내입니다. 각 확장 항목의 ‘더 알아보기’에서 경전 속 역할·도상 구별·예외·연관 용어·출처를 읽습니다. 임의의 부처·보살 이미지나 큰 배너, 새 라이브러리는 추가하지 않았습니다.

추가 JS·CSS·45KB 데이터 JSON은 **사전을 열 때만** 요청합니다. 홈페이지 초기 요청에는 포함되지 않습니다. 초기 HTML에는 작은 연결 함수만 추가했습니다. [파일 크기와 gzip 추정값](delivery-size.json)은 실제 휴대폰 회선의 지연 시간 측정값이 아닙니다. 재열기에는 이미 읽은 데이터를 재사용합니다.

확장 JS나 JSON을 불러오지 못하면 기존 검색을 계속 쓰며 다시 불러오기 버튼을 제공합니다. 검색 중 로딩이 완료되더라도 마지막 입력값을 유지합니다. 서비스워커 캐시는 v24로 갱신했습니다.

## 내용·출처 검토

[직접 열람한 25개 출처, URL·확인일·본문 SHA256](sources-reviewed.json). 한국민족문화대백과사전의 개별 본문과 국가유산포털의 다보탑 상세 설명을 직접 읽었습니다. 국가유산포털은 화면 껍데기가 아니라 실제 설명이 들어 있는 AJAX 본문까지 확인했습니다. 원문 이미지나 긴 문장을 복제하지 않고 새 문장으로 쉽게 정리했습니다.

- 석가모니는 역사적 부처로, 연등불과의 만남·다보여래의 보탑 이야기는 경전의 이야기로 설명합니다.
- 비로자나·노사나는 한국의 대표적인 삼신불 도상에서 구분하되, 번역·교학 전통에서 같은 부처의 이름으로 이해하기도 함을 명시했습니다.
- 법신·보신·화신은 세 역사 인물을 나누는 개념으로 설명하지 않습니다. 보신을 다른 맥락에서 아미타·약사와 연결하는 풀이도 구분합니다.
- 삼세불·삼존불 구성, 협시존의 종류, 법당 이름과 실제 봉안 대상은 시대·사찰별 차이를 안내했습니다.
- 수인이나 약그릇, 보관, 반가사유 자세 하나만으로 존명을 확정하지 않습니다.
- 미륵보살의 현재 모습과 미래에 성불한 미륵불을 구분합니다. 반가사유상의 존명 및 미래불 출현 시기의 차이도 단정하지 않습니다.
- 다보탑의 경전 관련 의미와 실제 건축·역사를 단순히 동일시하지 않습니다.

원래 사전에만 있던 나머지 용어 전체를 새로 출처 검증했다고 주장하지 않습니다. 출처 링크는 직접 열람하고 확장 설명의 근거로 사용한 항목에만 연결했습니다.
