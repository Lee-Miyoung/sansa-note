# 장소 대표 이미지 제작 검토 목록

현재 카탈로그 기준 사찰 111곳, 산 100곳. 아래는 **사진이 없다고 확정한 목록이 아니라**, 로컬 대표 그림이 없는 장소의 제작 검토 대장입니다. 외부 사진 제공 서버가 작업 환경에서 403을 반환하여 실제 사진 가용성·참고 자료의 내용을 검증하지 못했습니다. 따라서 장소별 그림을 임의 생성하지 않았습니다.
