# 산사 비밀도감 — 해인사 이미지 제작 사양

기준 시안은 UI로 재구현하고 시안 자체를 자르거나 배경으로 사용하지 않는다. 기존 `monk-reading.png`의 얼굴 비율·볼·수채화 결을 유지한다. 역사 장면은 모두 창작 복원도이며 유물 사진으로 표시하지 않는다. 인쇄 원본은 별도 PNG, 웹에는 WebP를 제공한다.

예정 파일: `haeinsa-cover`, `scene-01`~`scene-12`, `card-01`~`card-03`, `goods-preview`.
- 표지: 가야산 사찰의 봄·동자승의 책, 가로형.
- 장면 01: 1232년 초조대장경 소실을 상징하는 불과 빈 기록 공간. 폭력적 묘사 없음.
- 02: 고려 판각 공방, 여러 장인의 협업.
- 03: 경판에 글자를 새기는 손과 작은 붓.
- 04: 산벚나무와 돌배나무, 목재 선택 공방.
- 05: 강화의 보관 공간, 목판을 정리하는 사람들.
- 06: 1398년 이운을 상징하는 포장 경판과 사람들. 특정 운송 경로 재현 금지.
- 07: 연구자의 지도와 사료. 경로선·지명은 이미지에 넣지 않음.
- 08: 가야산 해인사와 경판을 맞이하는 사람들, 상징적 연출.
- 09: 장경판전 외부 건축.
- 10: 장경판전 창과 바람, 비문자적 시각화.
- 11: 경판 선반과 나뭇결, 시간이 흐르는 따뜻한 빛.
- 12: 다음 세대에게 책을 건네는 모습.
- 카드 01: 목판 판각/글자, 02: 포장 경판의 여정 상징, 03: 장경판전 창과 보존. 세로형, 텍스트는 UI로 별도.
- 굿즈: 엽서·책갈피·키링·머그의 비판매 콘셉트 일러스트.

역사 원문 접근이 불가능한 경우 제작 그림도 역사적 복원으로 보증하지 않는다. 공개 원고 검증 상태와 분리한다.
