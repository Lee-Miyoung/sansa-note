# 기타 순례지·CNN 코스 요청 작업 상태

## 완성한 초안

사용자가 이름을 특정하지 않은 구례 명소는 **사성암**으로 가정했습니다. 화엄사는 이미 한국 명찰 108선과 구례·곡성 코스에 있습니다.

- 사성암을 전라·구례·문척면 오산의 **기타 사찰**로 추가했습니다.
- 기존 `gurye_gokseong` 코스 구성은 유지하고, 신규 `gurye_saseongam` 코스에 사성암·화엄사·천은사·연곡사 네 곳을 연결했습니다. 기존 코스의 완주 여부·진행률·기록을 바꾸지 않습니다.
- 108선 배열·번호는 변경하지 않습니다. 사성암은 108 수호카드나 108 방문 수에 포함되지 않습니다.
- 기타 목록 제목을 ‘기타 사찰 · 내가 추가한 순례지’로 바꿔 편집자가 추가한 기타 사찰도 분명히 구분했습니다.
- 공유마당에 공개된 EBS 건축 사진과 전남도 소개 자료를 직접 열람해 사성암 수채화·방문 정보 카드 3개·출처를 연결했습니다. 현재 셔틀 요금·시간·GPS 좌표는 확인되지 않아 넣지 않았습니다.
- 사용자의 사찰 ID·메모·사진·방문 기록은 수정·마이그레이션하지 않습니다.

## CNN 코스: 미완료·미게시

CNN Travel의 아름다운 한국 사찰 기사는 현재 환경의 네트워크 정책에서 HTTP CONNECT **403**으로 차단됩니다. 기억으로 개수·순위·사찰 목록을 만들어 CNN 선정이라고 게시하지 않았습니다. [확인 대기 메타데이터](cnn-source-review.json)는 앱 코스에 포함하지 않습니다.

기존 접속 도메인 네 개를 유지한 채 `www.cnn.com`, `edition.cnn.com`, `cnn.com`, `www.gurye.go.kr`를 환경 설정 **초안**에 추가했습니다. 설정 도구는 `status: saved`, `requires_publish: true`를 반환했습니다. 현재 실행 환경은 revision 1과 기존 네 개 도메인을 유지하고 있어 아직 허용된 상태가 아닙니다. 사용자가 환경 설정에서 검토·저장 후 환경을 게시하면, 새 접속으로 원문을 확인하고 코스 구성·출처·기존 108선 밖 사찰을 확정해야 합니다.

사성암 변경은 사용자 배포 요청에 따라 이 보고서를 포함한 커밋으로 GitHub Pages에 배포합니다. 실제 운영 확인 결과와 커밋 SHA는 최종 응답에 보고합니다. CNN 전체 코스는 미완료 상태로 분리합니다.

환경 접근 절차는 [cloud-environment-runtime SKILL.md](skill://plugin_connector_1p_c5b7d5df5d7081918f2c4be5a633ed5d/cloud-environment-runtime/SKILL.md)의 “If it explicitly denies the destination, use the environment change flow described above.” 지침을 따릅니다. 접속 차단은 실제 프록시 응답이고, 환경 게시 필요는 설정 도구의 `requires_publish: true` 응답입니다. 앱 배포 승인이나 자격 증명을 다시 요구하는 것이 아닙니다.

- [조사 자료·권리·해시·원화 경로](saseongam-research.json)
- [EBS 사진(공유마당, CC BY 4.0)](https://gongu.copyright.or.kr/gongu/wrt/wrt/view.do?menuNo=200018&wrtSn=13068600)에서 전각·지붕·기둥·계단을 직접 확인했습니다.
- [전남도 보도자료(2014, 공공누리 1유형)](https://gongu.copyright.or.kr/gongu/wrt/wrt/view.do?menuNo=200019&wrtSn=12945655)에서 명칭 전승과 지형·조망 설명을 확인했습니다. 2014년 지정예고를 현재의 새 지정 사실로 표시하지 않았습니다.
- 사진을 생성 도구에 넣거나 앱에 복제하지 않았습니다. 확인한 건축 특징을 텍스트로 정리해 새 수채화를 생성하고 원화·압축본·목록/상세 표시를 육안으로 검토했습니다. 실측 복원도나 전문가 감수 완료로 표시하지 않습니다.
- CNN 원문 33곳 전체 명단은 여전히 미대조입니다. 추가로 공유마당 자체 검색에서 CNN 사찰 관련 공공자료를 찾았으나 전체 33곳을 검증할 목록은 확보하지 못했습니다. 이 사실을 숨기고 CNN 코스를 완성했다고 보고하지 않습니다.

전체 카탈로그 회귀 검사 `tests/catalog-complete.cjs`가 Chromium 390px에서 통과했습니다: 방문 정보 112곳, 실제 디코딩된 원화 212개, 목록 배치 214개(사용자 장소 포함), 기존 사용자 메모·사진·방문 기록 보존. [검사 결과](catalog-test-chromium-390.json). 신규 사성암 검색·실제 상세 진입·그림 디코딩·3개 방문 정보 카드 연결은 390/1440px에서 통과했습니다.
