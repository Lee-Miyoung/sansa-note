# CNN 관련 참고 사찰 코스 · 사용자 제공 37곳

사용자가 채팅에 제공한 목록을 기준으로 구성했습니다. 지역별 수는 수도권 3·강원 3·충청 5·전라 17·경상/부산 9, 합계 37곳입니다. CNN 원문 전체 명단과의 일치는 대조하지 못했으며, 데이터의 `cnnArticleVerified`는 `false`입니다. 코스 목록·상세·진행 화면에 ‘사용자 제공 참고 목록’과 원문 검증 상태를 표시합니다.

## 반영한 구성

기존 코스와 같은 `PACKS`·상세·진행률·완주·메인 불러오기 구조를 사용합니다.

- 전체 참고 37곳: `cnn_beautiful_temples`
- 수도권: `cnn_capital`
- 강원: `cnn_gangwon`
- 충청: `cnn_chungcheong`
- 전라: `cnn_jeolla`
- 경상·부산: `cnn_gyeongsang`

37곳 중 기존 108선에 포함되는 곳은 28곳입니다. 기타 사찰은 천축사·망경사·삼화사·보탑사·사성암·탑사·내장사·강천사·대전사 9곳이며, 사성암은 앞선 배포에서 이미 반영했습니다. 이번에는 새 장소 8곳을 추가합니다. 기존 108선 배열과 기존 코스 정의는 바꾸지 않습니다.

기존 사용자의 방문·사진·메모·사찰 ID를 변경하거나 옮기지 않습니다. 새 코스가 같은 장소를 참조하므로 기존 방문 기록을 재사용합니다. 코스를 반복해서 불러와도 장소를 중복 생성하지 않는지 모의 Firebase 브라우저 검사로 확인합니다. 사용자가 직접 등록한 오기 명칭을 임의로 새 이름으로 마이그레이션하지 않습니다.
